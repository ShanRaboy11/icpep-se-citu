# client

The Next.js (App Router) frontend for the ICpEP.SE CIT-U Chapter website.

Bootstrapped with `create-next-app`; see the [repo root README](../README.md) for setup, environment variables, tests and the git workflow, and [../AGENTS.md](../AGENTS.md) / [../docs/](../docs/) for architecture notes.

```bash
npm run dev           # http://localhost:3000
npm run build
npx tsc --noEmit
npm run lint
npm test
```
